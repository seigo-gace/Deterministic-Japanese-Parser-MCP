# Comprehensive Dictionary Expansion 2026-08

## Purpose

This expansion treats the previous 48-expression addition as only the first wave. The second wave broadens deterministic Japanese coverage across written language, everyday conversation, workplace dialogue, software operations, customer support, security, privacy, UI/UX, indirect speech acts, and discourse repair.

Runtime remains non-AI and offline. External corpora are used only to inspect usage domains and discourse functions; definitions, labels, patterns, and Gold cases are authored specifically for this project.

## New deterministic rule coverage

All 21 existing intent types receive six additional practical patterns:

`action`, `comparison`, `completion_criteria`, `condition`, `correction`, `decision`, `dependency`, `exception`, `modify`, `out_of_scope`, `premise`, `preserve`, `priority`, `prohibition`, `question`, `reference`, `remove`, `request`, `scope`, `sequence`, and `verification_criteria`.

Each new rule must satisfy all of the following:

1. It is compiled successfully.
2. It has a proven mandatory literal and is indexed; no new rule may fall back to always-scan.
3. Its dedicated Gold sentence matches the rule itself.
4. The final Meaning Graph compatibility view contains the intended intent type.
5. Prohibition and out-of-scope cases deny external-action execution.
6. Indexed and exhaustive execution remain semantically identical.

## Modular dictionary loading

Large future expansions no longer require rewriting the monolithic canonical files. `synonyms.d/*.yaml` and `task_templates.d/*.yaml` are loaded after the original `synonyms.yaml` and `task_templates.yaml`, then merged deterministically. The wheel package includes both fragment directories and offline installation tests must prove that the fragments are available outside the repository.

## Adoption policy

- Prefer multiword expressions whose practical interpretation can be made explicit.
- Require contextual evidence for expressions that also have a common literal reading.
- Do not infer hierarchy, emotion, refusal, or approval from politeness alone.
- Preserve indirect refusal, hesitation, concern, and information requests as distinct pragmatic functions.
- Keep ambiguous expressions unresolved when context cannot select a safe interpretation.
- Do not copy corpus passages or third-party dictionary definitions.

## Excluded or deferred surfaces

Single-word slang and extremely broad verbs remain deferred unless they are paired with a discriminating context or longer construction. Examples include `やばい`, `えぐい`, `神`, `回す`, `落とす`, `刺す`, and `飛ばす`. These surfaces can change polarity or meaning by generation, community, domain, and local context, so adding them as unconditional deterministic mappings would reduce safety.
